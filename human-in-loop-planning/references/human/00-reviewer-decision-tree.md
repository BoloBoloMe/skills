# HILP 审查员决策树

1. 先确认自己被要求决定什么：设计批准、蓝图批准、交接审核、重审裁决，还是归档确认。
2. 若事实、范围、风险或验证口径缺失，要求补充，不要批准。
3. 若设计仍有未决取舍，停在 phase-02；不要推进到蓝图。
4. 若蓝图缺少文件范围、顺序、停止条件或验证契约，停在 phase-03。
5. 若交接缺少 approved design、approved blueprint、closed handoff 或 HILE owner，停在 phase-05。
6. 若新事实推翻已批准资产，进入 phase-04 重审。
7. 只有当 review-pack 给出唯一具体固定命令，并且该命令与本次 decision 类型一致时，才复制命令。
