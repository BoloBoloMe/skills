证据：

- `git status --short -- superpowers | wc -l` 输出 `147`。
- `git diff --cached --name-only -- superpowers` 非空。

影响：

- 目标文件本身符合 v2 蓝图。
- 但当前 git 暂存区包含禁止路径，若一起交付，将违反 v2 执行交接。

建议：

- 交付本轮 v2 修改前，必须隔离或清理 `superpowers/` staged 变更。
- 后续禁止路径验证应同时检查 unstaged 和 staged：

```bash
git diff --name-only -- superpowers | grep . && exit 1 || true
git diff --cached --name-only -- superpowers | grep . && exit 1 || true
```
