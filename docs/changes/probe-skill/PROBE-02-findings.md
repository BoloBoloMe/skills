# PROBE-02 结论: markdown 模板

## 类型标签

四类，无前缀:

- `research` — AFK, 阅读/搜索/分析, 产出摘要
- `prototype` — HITL, 廉价原型提升讨论保真度
- `grilling` — HITL, 盘问敲定决策
- `task` — HITL 或 AFK, 解除决策阻塞的手动工作

Item 文件头 `类型` 字段使用。

## Item 模板

```markdown
# 状态: <待处理|进行中|已关闭>
# 类型: <research|prototype|grilling|task>
# 阻塞于: <PROBE-NN|无>

## 问题

<本 Item 要解决的决策或调查>
```

规则:
- 三种状态: `待处理` (初始) → `进行中` (已认领) → `已关闭` (已完成)
- 无阻塞时写 `阻塞于: 无`
- 答案不写入 Item 正文 — 写入独立产物文件, 通过 Backlog `已关闭决策` 链接

## Backlog 模板

```markdown
# <标题>

## 目的地

<到达时的样子>

## 笔记

<领域; 应查阅的 skill; 固定偏好>

## 已关闭决策

- [<Item>](链接) — <一句话摘要>

## 前沿

- [<Item>](链接) — `<类型>` — <问题简述>

## 未决迷雾

<尚无法写成 Item 的模糊视图>

## 范围外

<有意识排除的工作>
```

规则:
- 前沿: 开放 + 已解除阻塞 + 未被认领的 Item
- 已关闭决策: 每项一句话摘要 + 链接产物文件
- 未决迷雾: 范围内但尚无法精确表述 — 随前沿推进转化为 Item
- 范围外: 有意识排除, 标注原因
