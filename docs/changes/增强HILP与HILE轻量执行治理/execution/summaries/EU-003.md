## context_packet 核验

- approved_blueprint_ref：`stage-4-5/implementation-blueprint@v1 [state=approved｜中文状态=已批准]`

- required_sections：Context Packet、EU-003、执行范围、禁止越界项。
- relevant_decisions：执行阶段只读取当前 execution_unit 所需上下文；不重读全部历史规划资产；不让旧方案污染执行。
- prior_summaries：已读取 EU-001 summary、EU-002 summary。
- explicitly_ignore：待审批资产、待修订资产、已废弃方案。
