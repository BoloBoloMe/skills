## 实现内容

- 在 HILE 入口加入 `references/failure-forensics.md` 资源加载与路由规则，声明重复同类失败、越界需求或新事实触发停止、取证、分类和回退。
- 新增 Failure Forensics reference，定义触发条件、Failure Note 模板、证据字段、失败分类、禁止继续修复和 HILP 回退出口。
- 更新系统化调试规则，将第二次同类失败、越界文件需求、接口或验证口径变化、新事实推翻资产列为 failure forensics 转入条件。
- 更新完成前验证规则，要求完成声明前确认不存在未关闭 Failure Note；若存在则不得声明完成。
