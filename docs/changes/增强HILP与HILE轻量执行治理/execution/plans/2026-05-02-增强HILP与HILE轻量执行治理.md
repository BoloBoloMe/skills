- 任一 execution_unit 需要 HILE 执行阶段补做规划判断。
- 任一 execution_unit 需要新增 runtime 机制。
- 验证口径无法具体化。
- HILE 被要求在执行阶段临场定义验收口径。
- 执行者需要自行搜索未绑定资产来判断实现路线。
- context_packet 引用未批准或已失效资产。
- 无法写入 unit summary。
- 无法更新 execution ledger。
- 发现新事实或偏差但 summary 未标记是否需要重审。
- 第二次同类失败。
- 需要修改 allowed_files 之外的产品文件。
- 需要改变接口、数据形状、验证口径、发布顺序或禁止越界项。
- 出现新事实推翻已批准资产。
