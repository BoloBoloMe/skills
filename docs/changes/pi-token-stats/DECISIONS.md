# 决策账本 — Pi Token 统计插件

> 仅供 AI 使用. 改变决策内容/状态/约束性前须取得用户确认.

## D001: 数据源为 API usage 字段

- **状态**: 当前有效
- **约束性**: 必须遵守
- **决策**: Token 统计数据源为每轮 API 响应的 `usage` 对象 (`{input_tokens, output_tokens, cache_creation_input_tokens, cache_read_input_tokens}`), 不自己实现 tokenizer 估算.
- **理由**: API 返回值与计费一致, 避免本地 tokenizer 偏差; cache 字段仅在 API response 中暴露.
- **预计影响**: 插件通过 `ctx.getContextUsage()` 或遍历 session entries 的 `message.usage` 获取数据.
- **相关 issue**: ITEM-01

## D002: 分类维度从 usage 字段派生

- **状态**: 当前有效
- **约束性**: 可调整
- **决策**: 统计分类不发明新维度, 直接从 API usage 已有字段派生. Input 可进一步拆分为 system prompt / messages / attachments 等来源.
- **理由**: 与计费一致, 避免与 API 定义冲突.
- **预计影响**: ITEM-03 分类体系设计.
- **相关 issue**: ITEM-01, ITEM-02, ITEM-03

## D003: 不做计费/预算控制

- **状态**: 当前有效
- **约束性**: 必须遵守
- **决策**: 插件只做 token 统计, 不做费用估算, 预算控制或用量告警.
- **理由**: 范围约束, 聚焦核心功能. 定价表随模型变化频繁, 维护成本高.
- **预计影响**: 无费用相关代码.
- **相关 issue**: BACKLOG 范围外

## D004: 命令命名为 /usage

- **状态**: 当前有效
- **约束性**: 必须遵守
- **决策**: 注册 slash 命令 `/usage`, 不使用 `/cost` 或 `/tokens`.
- **理由**: 功能定位精确 (token 统计, 不含计费), 语义清晰, 避免 `/cost` 暗示计费的误导.
- **预计影响**: `pi.registerCommand("usage", { handler })` 注册.
- **相关 issue**: ITEM-04

## D005: 仅命令入口, 无其他交互方式

- **状态**: 当前有效
- **约束性**: 可调整
- **决策**: 插件只提供 `/usage` 命令, 不注册 LLM 可调用工具, 不做状态栏/Widget 持续显示, 不做 turn_end 或 agent_settled 自动通知.
- **理由**: 简化初版, 用户主动查询为主. 后续可按需添加.
- **预计影响**: 无 `registerTool` 调用, 无 `setStatus`/`setWidget` 调用, 无事件处理.
- **相关 issue**: ITEM-04

## D006: 输出为 overlay 弹窗

- **状态**: 当前有效
- **约束性**: 必须遵守
- **决策**: `/usage` 执行结果通过 `ctx.ui.custom({ overlay: true })` 展示为浮动卡片, 不写入对话消息/JSONL.
- **理由**: 统计为临时查询, 不需要持久化到会话记录. overlay 关闭即消失, 避免污染对话.
- **预计影响**: overlay 组件实现; 结果不可回溯, 用户需重新执行 `/usage` 再次查看.
- **相关 issue**: ITEM-04

## D007: 仅统计当前会话

- **状态**: 当前有效
- **约束性**: 可调整
- **决策**: `/usage` 无命令行参数, 仅统计当前活动会话; 不支持查询历史会话或项目/全局汇总.
- **理由**: 初版聚焦最小可用. 历史会话查询和跨会话汇总留后续扩展.
- **预计影响**: 使用 `ctx.sessionManager` 获取当前 branch entries; 无需参数解析.
- **相关 issue**: ITEM-04

## D008: 完整明细卡片, 每行含占比

- **状态**: 当前有效
- **约束性**: 可调整
- **决策**: 卡片展示所有分类维度的完整明细, 每行显示 token 数量和占总计百分比. 分类骨架为 输入(系统提示/对话消息/附件), 缓存(读取/写入), 输出(模型输出), 底部合计行 + 缓存命中率 + 对话轮数.
- **理由**: 用户主动查询时通常需要完整信息而非摘要. 占比提供直观的成本分布感知.
- **预计影响**: overlay 组件渲染分类行, 百分比计算以 Total 为分母.
- **相关 issue**: ITEM-04
- **未决依赖**: ITEM-03 分类体系确定后替换具体行标签. 三大类 (输入/缓存/输出) 预期不变.

## D009: 界面全中文

- **状态**: 当前有效
- **约束性**: 必须遵守
- **决策**: 卡片内所有标签使用中文: 输入, 系统提示, 对话消息, 附件, 缓存, 缓存读取, 缓存写入, 输出, 模型输出, 合计, 缓存命中, N 轮对话.
- **理由**: 用户偏好.
- **预计影响**: 组件内 label 字符串.
- **相关 issue**: ITEM-04

## D010: 不提供导出功能

- **状态**: 当前有效
- **约束性**: 可调整
- **决策**: 不做 JSON/剪贴板/文件导出, 仅 overlay 查看.
- **理由**: 初版最小化, 无明确导出需求.
- **预计影响**: 无导出相关代码.
- **相关 issue**: ITEM-04
