## 主战场

**攻决策25**. 理由: 19-29 的忠实性承重结构 = 机械产稿 (23/24) + 独立会话检查 (25). m3 建立的闸门体系 (决策15) 的执行者, 时点, 复查深度全部由决策25 重新安排; 而修文是决策18 定下的常态路径 (闸门发现的真缺口都走修文), 不是例外. 决策25 与仍有效的决策15 在 "修订后检查覆盖范围" 上字面冲突, 且账本同时把两条标为 当前有效/必须遵守. 拆这一环等于让忠实性承重墙在最常发生的场景 (修文) 上处于无定义状态, 决策19 "机检与独立对账保证忠实" 的承诺在该场景失去可判定的语义.
