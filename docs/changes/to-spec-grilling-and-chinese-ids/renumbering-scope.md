# 编号汉化改动清单 (milestone-01 输入重建)

原侦查报告 `/tmp/navigate-scout/C-renumbering-scope.md` 随容器重置丢失, 本文件按当前工作树 grep 重建, 供 milestone-01 使用.

## 折算规则

| 旧写法 | 新写法 | 说明 |
| --- | --- | --- |
| `D001` / `D002` | `决策1` / `决策2` | 决策账本条目, 正文不带前导零 |
| `F001` | `事实1` | 事实账本条目 |
| `G-001` (正文条目) | `目标1` | PRODUCT.md 目标节 |
| `NG-001` (正文条目) | `非目标1` | PRODUCT.md 非目标节 |
| `BR-001` (正文条目) | `规则1` | PRODUCT.md 业务规则节 |
| `AC-001` (正文条目) | `验收1` | 只出现在执行拆分与覆盖矩阵, Gherkin 里没有正文条目 |
| `TC-001` | `用例1` | 覆盖某验收的主用例与验收同号: `验收5 -> 用例5` |
| `TC-02-01` | `用例2-1` | issue 与序号都不带前导零 |

对账口径: Gherkin 标签保留拉丁三位 (`@G-001` / `@BR-001` / `@AC-001`), 与正文条目差一个前导零, 机检按去掉前导零后的数字比对: `@G-001` 对 `目标1`, `@BR-002` 对 `规则2`.

不改: Gherkin 标签本身, `ISSUE-<两位>` 文件名前缀, 里程碑 id `milestone-01`, 历史文件 (docs/changes 已关闭变更, docs/adr) 与指向历史条目的引用 (`D003` / `D005` / `D007` / `D008` / `D011` / `D012` 等, 全是旧账本条目).
