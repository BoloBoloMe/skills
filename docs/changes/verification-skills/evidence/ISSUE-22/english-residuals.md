# 残留英文与保留理由

扫描命令与名单见 `machine-checks.log` 末段. 全部属允许类型, 无普通 prose 英文.

| 词 | 次数 | 类别 | 理由 |
| --- | --- | --- | --- |
| `name`, `description`, `disable-model-invocation` | 各 1 | frontmatter key | 技能元数据字段名, 不可译 |
| `benchmark-checklist` | 1 | skill 名 | 技能目录名, 与目录一致 |
| `blast-radius` | 1 | skill 名 | 另一个技能名, 引用其调查方法 |
| `uptime`, `nproc` | 各 1 | 命令名 | 采集负载与核心数的真实命令 |
| `await`, `true` | 各 1 | 代码关键字 | 描述异步任务与布尔值 |
| `p50`, `ms` | 1, 2 | 单位与指标 | 延迟分位数与毫秒单位 |
| `PR` | 3 | 术语 | 对外报告载体, 仓库已有共享用法 |
| `Git` | 1 | 术语 | 版本控制工具名 |
| `CPU` | 1 | 术语 | 命中率与硬件指标 |
| `TC` | 2 | 术语 | 一次性实验记录里的用例标记, 沿用既有用法 |
| `A`, `B`, `B...` | 2, 1, 1 | 两侧标号 | 交替测量序列 `A,B,A,B...` 的标号 |
| `r` | 3 | 公式变量 | 收益上限公式 `r / (1 - r)` 的占比变量 |

本轮改动没有新增英文词: 修前名单与本轮一致 (见 `diff.patch`, 新增句只用中文与反引号节名).
