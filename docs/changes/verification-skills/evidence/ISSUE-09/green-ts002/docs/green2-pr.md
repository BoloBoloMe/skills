# 报表导出: 优化 normalize 阶段

## 概要

把报表导出中 normalize (逐行 trim + 转小写) 的实现换成更快的写法, 输入输出格式与内容不变. 其余三段 (parse / render / write) 未改动.

## 性能

2000 行报表导出, 单次端到端中位耗时 103.15 ms -> 75.11 ms (降 27.2%).

测量方法, 完整次数, 极差, 失败数与机器条件: [docs/green2.md](docs/green2.md).

## 正确性

每侧 7 次交替运行, 失败 0 次; 每次运行写出 2000 条, 输出摘要与独立重算的期望值全部一致.

## 范围与限制

- 数据规模 2000 行, 单线程, 无并发; 测的是 run_report() 端到端全程, 不是函数级微基准.
- 本仓库所有耗时由 time.sleep 模拟, 这个数字证明测量方法与判定流程, 不代表真实产品性能; 上线前需在真实实现上重测.
