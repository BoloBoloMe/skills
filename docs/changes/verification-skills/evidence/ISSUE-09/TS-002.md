## 缺口与风险

- 数字全部来自 `time.sleep` 模拟, 只证明结论写法与判定边界, 不代表真实产品性能.
- PR 草稿里的证据链接指向项目内记录文件 `docs/green2.md`, 真实仓库里应换成该证据材料的实际位置; 本次演练没有真实远端仓库, 未验证换链后的可读性.
- 单模型单宿主 (16 核, pi 1.3.0, herdr 0.9.4). 红轮只在本模型上跑红一条 (PR 主数字), 其余如实记录为未跑红.
