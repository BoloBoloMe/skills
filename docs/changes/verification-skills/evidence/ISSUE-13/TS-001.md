- 本切片不做会话演练: 静态交付物由机械检查核对, 行为保真演练在 `TS-002-drill.md`.

## 绿轮 (实现后)

实现内容:

- `workflow/blast-radius/LICENSE` 与 `workflow/benchmark-checklist/LICENSE`: 逐字节复制上游 `pstack/LICENSE`, 完整 MIT 含版权行 `Copyright (c) 2026 Lauren Tan`, 授权段, 随附条件段与全大写免责段. 三份 sha256 同为 `bc957ca6bee02792566a1a028d105e02e247c6e77cf057061674273da77b200e`.
- `workflow/blast-radius/reference/PROVENANCE.md`: 由原 `source-record.md` 改名并扩写 (`git mv`), 补固定 SHA 与不追 main 的声明, 抓取命令与实测 HTTP 200, 15 行逐项差异表 (源版位置, 目标版位置, 影响, 处理决定), 第 7 节三条校验命令与结果, 行为保真演练入口.
- `workflow/benchmark-checklist/reference/PROVENANCE.md`: 新建, 同样字段, 16 行逐项差异表.
- `workflow/benchmark-checklist/SKILL.md`: 补回上游第 3 问的物理上限算式 (每秒字节数对带宽, 每秒操作数乘每操作成本对核心数, 省下的时间对被改动那一段耗时), 理由与决策记在它自己的差异表里.

## 结论

- TC-102 满足: 两个包内都能直接读到完整 MIT 文本; 固定 SHA 与逐项差异表在包内可复核; 不以作者名或外部链接代替许可与记录.
- 差异表字段齐全 (源版位置, 目标版位置, 影响, 处理决定), 每条差异都有处理决定, 其中 benchmark-checklist 的物理上限算式是本次补齐的项, 已单列.
- 机械检查不冒充翻译校验: `check_skill.py` 只用于 frontmatter, 标点与残留英文按 translate-a-skill 第 7 节命令核对, 记录写进两个 `reference/PROVENANCE.md`.
