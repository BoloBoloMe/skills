# drill-G6: 3 个微小只读检查组共用一份准备, 3 名可用非作者 (AC-005-3)

## 目的

改动后的技能在"3 个都能独立做的微小只读检查, 但都读同一份构建产物, 每开一个新会话都要重跑同一次准备"时, 是否只派 1 人依次做完, 不因组数派满 3 人.

## 待测版本

- 源文件 md5 `9ac67b01f3e9a5d3714e3292dcba6277`, 原件 `../logs/SKILL-v2.md`.

## 夹具与输入

- 夹具: `/tmp/orchestra-03/micro2/micro-groups`, 目标提交 `5d3765e9b0d8228b8738a75ea69baef048402c45`, 3 个场景 (读 `dist/app.txt` 第 1/2/3 行) 且没有审计 BR; 共 3 项必验.
- 准备成本是这台夹具的关键前提: `bash prepare.sh` 每次生成同一份 `dist/app.txt`, 单次实测 22.26 秒 (见 `REPORT.md` 的 AC-001-1 行), `dist/` 不进仓库, 每个新会话都要重跑.
- 任务输入: "本轮最多可开 3 个验收子会话".
- 指挥者: `i03-g5b`, 会话 `01a15438-e21c-713b-b21b-c8256e923b49`, 启动 20:52:56 CST.
- 验收者: `acc-g5b-1`, 会话 `01a15439-77f0-71ac-8f2f-b3f474f424da`, 启动 20:53:34 CST.

## 实际结果

- `PLAN.md` 写: 唯一场景组 G-A 承接三条场景; 可用 3 人, 计划 1 人; 理由是"三条场景共用同一份前置产物 dist/app.txt 和同一个 dist/ 路径, 拆给多人要各自重跑约 25 秒的 prepare.sh, 还会争用同一个产物, 准备成本与资源冲突都大于并行收益"; 结论"只派一人依次做完, 不按 AC 逐条开会话".
- 实际只起 1 个新验收会话; 验收者自己跑一次 `prepare.sh` (22.26s) 后连续读三行, 逐条留下 `cmp`/hex 原件; 指挥者 `product_runs=0`, `herdr_calls=9`.
- 3 项必验 / 1 个会话; 计划后直接启动, 无等待批准.

## 结论

- AC-005-3 通过: 多组但重复准备成本大于并行收益时只派一人, 原因写在计划里, 没有为凑组数派 3 人.

## 风险与限制

- 第一版微检查组夹具 (含审计 BR, 准备仅约 1 秒) 下, 技能把审计 BR 单独成组派了 2 人; 那份材料不满足本条前提, 已作废并记录在 `../incidents/fixture-corrections/README.md`, 旧产物存 `../incidents/micro-v1-plan2/`.
