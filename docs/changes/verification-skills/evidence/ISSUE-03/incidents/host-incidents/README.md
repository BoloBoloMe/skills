## 3. git-operation-gate 误拦

- 本机 pi 扩展 `git-operation-gate.ts` 会按命令文本匹配危险操作. 演练中出现两类误拦:
  - 命令里出现 `clean` 字样 (例如写文件名 `status-clean-excluding-evidence.txt`) 被当成 `git clean`, 提示"将永久删除未跟踪文件".
  - 长复合脚本里夹着 `git status`, 也触发同一条提示.
- 受影响会话: `i03-r1` (20:29 前后), `i03-h2` (20:41), `i03-h1b` (21:03 前后补充审计). 我作为演练操作者按提示选择"允许本次/本次会话都允许", 会话继续; 技能没有因此改变行为.
- 这是宿主扩展的判定规则问题, 不改待测技能, 也不改全局配置.
