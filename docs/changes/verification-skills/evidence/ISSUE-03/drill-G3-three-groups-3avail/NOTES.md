## 实际结果

- `plan.md` 写: 按子命令划 3 组, 可用 3 人, 计划人数 = min(3 组, 3 人) = 3; 依据是"三组之间无共享写入资源, 各用独立数据目录, 无必经构建/准备步骤, 主要工作量在批量场景, 三组并行有实际收益".

- 9 项必验 / 3 个会话, 没有逐条 AC 开会话.
- 指挥者 `product_runs=0`, `herdr_calls=13`; 计划写完后直接启动.

## 结论

- AC-005-1 的 (组数 3, 可派 3, 计划 3) 例子成立, 收益与资源依据写在计划里.
- 支持 AC-004-1: 3 名验收者都是本轮新会话, 启动时间 20:43 晚于实现提交时间 20:26.
