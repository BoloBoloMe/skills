# 显式 /usr/bin/python3 复跑 (补充证据, 不改判定)
utc=2026-10-19T15:18:10Z
背景: 本机 pi 全局扩展 python-operation-hook 会把 bash 工具调用里的 python3 命令替换成 uv run python.
钩子替换实证: 同一工具环境里 $ python3 -c 'import sys; print(sys.executable)' 输出 /home/bolo/.local/share/uv/python/cpython-3.14-linux-x86_64-gnu/bin/python3.14 (3.14.7);
而 command -v python3 = /usr/bin/python3 (指向 python3.14), /usr/bin/python3 --version = Python 3.14.4.
即: 字面 python3 未走 PATH 的 /usr/bin/python3, 实际被钩子改写为 uv run python (解释器 3.14.7). 两者同为 CPython 3.14 系列.
