### 主战场

P1 与 P4 的交界: 技术层承接与收尾门都由"同一个执行体系"自证. 选择理由: 本轮把三类难题 (加载错误状态, 带宽/核心上限, 历史定位与中文整理) 全部转给下游, 又把"节点是否发生"交给报告与收尾者的判断; 一旦承接可以合法地退化为文本检查或"不测理由", 或收尾判断可以自我解释, 整个 D040 策略就从"补了验证"变成"补了措辞". 拆这一环不动用户已定的产品范围, 但会削弱"技术收口等于问题解决"的结论.
