## 要构建什么

在 `workflow/verify-change/SKILL.md` 增加旧证据适用性与项目配方选择切片: 条件仍适用的旧观察可复用并引用原时间/版本/位置; 条件变化时只重跑受影响场景; 旧证据失效且无法运行时如实受阻; 验收开始后输入变化时旧报告只覆盖旧输入. 有项目级验证配方时优先使用, 配方过时按操作缺口报告, 不改成产品缺陷, 不私自修改或自动生成配方. 交付后, 临时项目中的旧证据复用, 重跑, 受阻和过时配方处理都可核对.
