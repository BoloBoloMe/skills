## 要构建什么

在 `workflow/benchmark-checklist/SKILL.md` 增加结论与粗估切片: 正式比较结论只能是更快/更慢/无可测差异/无法下结论, 附单位/次数/极差/限制因素; 缺限制因素, 单边未调优或第 4/7 问无法检查时无法下结论; 用户只要粗估时可单次, 但必须声明单次并查错误计数与工作是否发生, 异常时继续检查; 选型永不按粗估; PR 正文只放一个带单位/前后对照/证据链接的主数字, 完整证据不缩减. 交付后, 临时测量材料上的结论判定, 粗估边界和 PR 文本都可核对.
