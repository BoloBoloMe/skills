## 演练抓到的 8 个缺陷 (全已修, 已提交)

1. daemon 允许目录误传父目录 + 多余的"父目录独占"断言 (真实 Workspace 多仓库必触发) → 允许目录收窄为主仓本身, 断言删 (实测兄弟仓库 daemon 层直拒).
2. net-firewall 黑名单空名单时规则集无 saddr 行, 注入校验误报失败.
3. ssh-keygen 重入卡死 (文件已存在 → 交互问覆盖 → 非交互必死) → 已生成即复用.
4. hideRefs 漏 `refs/remotes` → origin/* 读面泄漏 (birth 自检逮住).
5. 彻底终结后 (stage idle) birth 无出口死锁 → idle 视为全新 birth.
6. 分支 ref 已存在时建母体 worktree 失败 → 存在则直接检出.
7. kimi CLI: 构建期 root 跑 uv tool, python 软链进 /root → 清单加 `UV_PYTHON_INSTALL_DIR=/opt/uv-python` + chmod.
8. 容器 env 不进 ssh 会话 (sshd 不传) → base 开 PermitUserEnvironment + birth 写 `~/.ssh/environment`.
