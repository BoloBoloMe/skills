### D018 端口留痕与换端口语义
- 状态: 当前有效
- 约束性: 必须遵守
- 内容: 端口默认值取 `state.json.last_port`, 没有才用首选 8090; 这样换过端口之后不会因为 `stop` 悄悄退回 8090, 让旧书签静默失联. `serve --port <N>` 在没有存活实例时可用 (含首次运行); 有存活实例时报错 `instance_running`, 要求先 `stop`. `stop` 不清端口记录: 把 `pid` 置空并写 `stopped_at`, 保留 `port` 与 `last_url`, 于是"已知停机"与"旧实例死掉的残留记录"能区分, 换端口时能报出真实旧地址而不是假定旧端口是 8090. 换端口成功后必须报告旧地址已失效, 并把新端口写入 `last_port`. 理由: m13 D022 要的是"不静默漂移", 而 stop 清记录会让换端口报不出真实旧地址, 还会造成下次静默回到旧端口.
- 依赖事实: m13 D022, m13 D024
- 预计影响: `stop`/`serve` 的状态读写; PRODUCT BR-004; TECHNICAL 状态字段与关键流程; AC-003/AC-004
- 实际影响: 待探索
- 需要调整: 无

- 状态: 当前有效
- 约束性: 必须遵守
- 内容: `--exclude <glob>` 是 glob 语义, 由脚本转成 ccsh 的 `-e` 正则 (元字符逐字转义), 不把 glob 原样当正则交给 ccsh; 默认排除集同样按此转换. 统计侧承认口径不可能完全对齐: ccsh 自己还会按 `.gitignore` 与测试/build 默认规则过滤, 这些文件在宿主扫描里被数进 `scanned_files` 却不在依赖树, 所以 `stats.excluded` 增加 `tool_defaults` 类别, 不逐文件复刻 `.gitignore`, 也不宣称逐文件精确. 非功能要求的"口径一致"改为"差值逐类归因可核对". 理由: 硬做逐文件复刻既脆又没必要, 把归因类别摊开, 用户能看懂分母是怎么来的.
- 依赖事实: m13 D017, m23 6.3, m23 6.4
- 预计影响: build 参数构造与统计字段; PRODUCT BR-015/BR-024; TECHNICAL 分析模块与统计
- 实际影响: 待探索
- 需要调整: 无
