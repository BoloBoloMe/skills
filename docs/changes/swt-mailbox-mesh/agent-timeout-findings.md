# 三 agent 工具超时实测记录 (ISSUE-10 / D018)

日期: 2026-09-20.

## 范围修订

用户裁决 (2026-09-20): 取信 agent 只会用 pi, codex/kimi 不需要实测. D018 的 "三种 agent 必测" 收窄为 "pi 必测".

## pi

- 实测方法: 在 pi 交互会话 (本会话) 中经 bash 工具执行 `sleep 600 && echo done`.
- 结果: 命令完整跑满 600 秒, 未被中途杀掉, 正常打印 done (20:31:07 → 20:41:07).
- 补充说明: 调用时显式给了工具 700 秒预算; 未测默认预算下限, 但 600 秒量级的阻塞长轮询在 pi 中可行已证实.
- 结论: pi 做取信 agent 无超时障碍, 阻塞长轮询模式成立.

## --wait 参数建议

- 无超时 agent, 无需 --wait 有界模式. 若将来引入有命令超时的新 agent, 再按其实测上限加 `--wait <秒数>` (取值略低于该上限即可, 脚本到点返回重试).
