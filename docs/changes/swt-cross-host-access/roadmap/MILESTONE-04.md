## 问题

网页访问设计已于 2026-09-14 盘问关闭. 权威结论: [M04 决策账本](../milestone-04/DECISIONS.md), ADR [0012](../../../adr/0012-container-web-direct-access.md).

## 结论

- 新容器发布 8800 到宿主动态端口, 直达局域网; present 多页复用单实例; STATE 登记 web-port, 每次只交付自身母体对应容器的双 URL.
- 一母体一个活跃容器, 不做多母体汇总页; 现有容器全部不处理.
- 接受重建后重新分享 URL, 稳定链接迷雾关闭.
- 容器经信箱询问当前设备 agent 查网址/回话/代开, 不新增容器 URL 文件; 无信箱时仍可点交付包链接.
- 页面就绪后在当前设备打开一次. 当前设备每次工作开始确定, 可从会话确定就自动记录, 否则问一次, 换设备时更新; 发信显式指定目标, 不靠最近轮询猜.
- 宿主地址优先沿用已确认值, 不确定时问用户, 不交付猜测链接.
