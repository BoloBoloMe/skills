# 容器网页通过固定容器端口直接交付, 信箱只增强设备侧操作

容器镜像声明的 8800 未被发布, present 生成页面后没有可交付的直达入口. 决策: 新建容器发布 `0.0.0.0` 上动态分配的宿主端口到容器 8800, present 复用现有单实例并监听 `0.0.0.0:8800`, host 交付当前母体对应容器的本机/局域网两条 URL. 用户接受无认证 web 内容和服务对局域网开放, 以便分享给同事; 不使用回环-only/手工隧道作主路径, 不保证链接跨容器重建稳定. 现有容器不改造.

容器 agent 经信箱询问设备 agent 取得网址并代开, 无信箱时仍能点击交付包入口访问. 自动打开的目标必须来自本次工作会话已确定的设备, 不能把最后来取信的设备当成人当前所在设备. 理由是多个取信会话会持续轮询, 轮询时序与人在何处无关. 此用途显式指定信箱目标, 不修改通用缺省路由. 具体约束和验收见 [M04 账本](../changes/swt-cross-host-access/milestone-04/DECISIONS.md).
