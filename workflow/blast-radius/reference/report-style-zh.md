# 中文交接的整理规则

交接稿成文前按本文件整理一遍. 这里借的是 unslop 的诚实与去冗意图, 不照搬它的英文写作清单: 英文清单盯的词汇和句式对中文报告不适用, 硬套会删掉中文里必要的边界说明. 下面按中文报告实际会犯的错写规则.

## 必须留

- 事实, 推断, 未证实三种状态的标签, 以及各自的证据级别.
- 风险的发生概率, 代价, 严重程度; 已排除项的覆盖范围.
- 数量, 版本号, `file:line`, 命令原文, 原始输出.
- 适用范围与已知缺口: 哪些结论只对某批数据成立, 哪些地方查不到.

## 可以删

- 客套, 铺垫, 结尾的自我评价.
- 同一结论的几种说法; 只留信息量最大的那一种.
- 没有证据支撑的形容词, 例如 "严重", "显著", "彻底"; 换成数字, 位置或条件.
- 复述技能本身要求的话.

## 句式

- 一句一个意思; 长句拆成动作链, 谁做了什么, 得到什么结果.
- 用大白话. 术语第一次出现时用一句白话解释, 别用行话代替结论.
- 结论在前, 证据在后: 读者先知道该不该合入, 再按需要读证明.

## 自检

逐段问一遍: 这段删掉, 会不会让人误判风险或漏掉边界? 会就留, 不会就删. 整理完的报告仍要能让别人照着重跑证明.
