# 中文交接的整理规则

交接成文前按本文件整理. 只借用 unslop 的诚实与去冗意图, 不照搬英文清单. 英文词汇与句式规则不适用中文, 硬套会误删必要边界.

## 必须留

- 事实, 推断, 未证实三种状态的标签, 以及各自的证据级别.
- 风险的发生概率, 代价, 严重程度; 已排除项的覆盖范围.
- 数量, 版本号, `file:line`, 命令原文, 原始输出.
- 适用范围与已知缺口: 限定数据的结论, 以及查不到的位置.

## 可以删

- 客套, 铺垫, 结尾的自我评价.
- 同义重述: 只留信息量最大的一种.
- 无证据的形容词: 如 "严重", "显著", "彻底". 换成数字, 位置或条件.
- 复述技能本身要求的话.

## 句式

- 一句一个意思. 长句拆成谁做什么, 得到什么的动作链.
- 用大白话. 术语首次出现就用白话解释, 不用行话代替结论.
- 结论在前, 证据在后. 先说该不该合入, 再给证明.

## 自检

逐段检查: 删掉会不会误判风险或漏掉边界? 会就留, 否则删.
完成标准: 事实, 推断与未证实分明. 必留材料齐全, 别人仍能照报告重跑证明.
