# workflow 元词汇表

## 语言

**权威输入**:
产物编写必须依据的上级输入文档集, 典型成员: PRODUCT.md / TECHNICAL.md / DECISIONS.md. 优先级: spec 优先于决策账本 (spec 是决策的提炼产物, 直接读账本费 token). 冲突时停止并盘问用户, 不自行改写权威方.
_避免_: 把会话中的口头指示当权威输入 (未落盘者不是); 绕过优先级直接读账本 (有 spec 时)

## 收录标准 (维护规则)

收录标准: ≥2 个 workflow skill 共用, 或单 skill 使用但定义非显然; 一眼自明的词不收. 新词须经用户审定才落盘.
