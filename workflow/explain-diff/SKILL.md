为指定的代码变更生成一份丰富的交互式解释.

包含以下四个部分:

- **背景**: 解释与此变更相关的现有系统. (应广泛探索变更周围的代码.) 读者水平未知, 因此同时包含面向初学者的深度背景 (熟悉者可跳过), 以及直接关联变更的窄幅背景.
- **直觉**: 解释代码变更的核心直觉. 聚焦于本质, 而非完整细节. 使用具体示例和 toy data. 大量使用插图和图表.
- **代码**: 对代码变更做高层走读. 以易于理解的方式对变更分组/排序.
- **测验**: 出五道题, 测试读者对本次变更的理解. 难度中等: 需要真正理解变更实质才能答对, 但不出偏题怪题. 目标是帮助读者确认自己是否真正理解了. 以交互式多选形式呈现, 点击后告知对错并给出反馈.

## 生成与展示

调用 `present` skill 生成并展示: 自包含 HTML 规范, 视觉风格, 临时目录与浏览器展示都由它负责. 本 skill 的增量要求:

- 顶层目录对应背景/直觉/代码/测验四部分.
- 测验的多选交互与点击反馈属于 present 有界交互的允许范围.
- 常用图表族: 极度简化的应用 UI 示意图 (解释 UI 变更), 系统图 (组件间数据流或通信).
