# 逻辑原型

单文件交互网页, 让我在浏览器里点按钮驱动状态模型.
当问题涉及业务逻辑, 状态转移或数据形态时使用, 这些在纸面上看似合理, 跑过真实 case 才发现不对劲.
单个自包含 HTML 文件: 内联 vanilla JS 和 CSS, 无第三方依赖, 无构建步骤, `file://` 双击直开.

原型文件放在 `docs/changes/<feature-slug>/prototypes/<prototype-name>/` 下.

## 流程

### 1. 陈述问题

写代码之前, 先写下要验证的状态模型和问题.
一段话即可, 放在原型文件顶部注释中.
把问题显式写出来, 以便事后核对.
完成标准: 问题陈述已写入原型文件顶部; 我能指出它是否命中了我关心的 case.

### 2. 将逻辑隔离为可移植模块

把真正回答问题的核心逻辑放在一个小而纯的接口后面, 与外围页面隔离. 页面是一次性的; 逻辑模块是我在正式代码中重写时的参考答案.

用什么结构组织逻辑, 取决于问题长什么样:

- **如果问题核心是 "操作是否合法"** (比如订单只能从"待支付"→"已支付", 不能从"已取消"跳过去) — 用状态机: 显式列出所有状态和合法转移, 非法操作直接拒绝.
- **如果问题核心是 "数据怎么变"** (比如计算折扣, 合并两个报表, 校验一组字段) — 用纯函数: 输入数据, 返回新数据, 不改任何外部状态.

实现上很简单: 状态用 plain object, 合法转移用 `switch` 或查表, 函数签名清晰.
逻辑集中在一个独立的 `<script>` 块, 保持纯净: 无 DOM, 无事件监听, 无渲染调用.
页面外壳经公共接口调用它; 数据不反向流动.

完成标准: 核心逻辑是独立的 `<script>` 块, 通过公共接口被外壳驱动; 块内不出现任何 DOM 引用; 接口干净到可作为正式实现的参照.

### 3. 构建自描述的最小页面

页面零学习成本: 能做什么全写在界面上, 不记键位, 不读说明.
每次操作后重渲染整个状态面板 (替换, 不追加).

页面三区:

1. **当前状态**, pretty-print 且 diff 友好 (每字段一行, 或 `JSON.stringify(state, null, 2)`). 本次操作中变化的字段高亮 — 我一眼看到什么变了, 不用自己 diff.
2. **操作按钮**, 每个操作一个按钮, 标签写操作全文 (如 "支付订单"), 不是单个字母键. 若逻辑以数据形式暴露当前合法操作, 非法按钮置灰, 让状态机直接可见; 否则点击后由逻辑拒绝.
3. **操作历史**, 每次点击追加一行: 操作名 → 结果或拒绝原因. 我试过的路径自动留痕, 替代终端 scrollback, 也直接服务捕获步骤.

行为: 初始化状态 → 点击按钮 → 逻辑模块计算 → 合法则更新状态并重渲染, 非法则状态不变且历史记录原因 → 循环直到我关闭页面. 全部内容应能在一屏内显示.

完成标准: `file://` 打开即见初始状态; 点击按钮后状态变化可见且变化字段高亮; 非法操作有明确反馈; 我不需任何说明即可开始操作.

### 4. 交付

把文件路径交给我, 我双击打开. 没有启动命令, 没有终端.
远程/ssh 场景用 present 的 web_server 挂载页面所在目录, 交付 URL.
有意义的时刻是我说 "等等, 这不应该是可能的" 或 "咦, 我以为 X 会不一样" —
这些是想法里的 bug, 正是原型要找的.
完成标准: 我已打开页面并开始点击; 或我确认看到预期行为.

### 5. 捕获

按 [SKILL.md](SKILL.md) 规则 5 捕获答案和原型.
操作历史是我试过的 case 的一手记录, 可直接摘入结论.
逻辑模块作为参考答案保留在工作分支 (`docs/changes/` 下), 由正式实现者参照重写;
页面外壳同样保留, 作为一手材料.
原型文件在合并主干前由人类清理.
完成标准: 答案已记录; 原型文件已归档; 实现 issue 上有指针.

## 反模式

- **不要加测试.** 需要测试的原型不再是原型.
- **不要泛化.** 不设想 "如果我们以后想支持 X". 原型只回答一个问题.
- **不要引入框架, CDN 或构建步骤.** 引入即告别 `file://` 直开, 也告别一次性定位.
- **不要装修.** 默认无样式或极少样式; 页面为读状态服务, 不为好看. 视觉投入是浪费.
- **不要把逻辑和渲染混在一起.** 状态机/纯函数里出现 `document` 就不再可移植.
- **不要把页面外壳交付到生产环境.** 外壳为浏览器手动操作优化, 逻辑模块的价值在于作为重写时的参考答案, 不在直接复用.
