# 产出物模板

## 目录结构

```
docs/reviews/
└── YYYY-MM-DD-<简短标识>/
    ├── 代码评审日志.md
    └── 人审报告.md
```

`<简短标识>` 用被 review 目标命名: `auth-module` / `PR-142` / `payment-refactor`.
若仓库无 `docs/` 目录, 退回到当前工作目录.

## 代码评审日志.md

```markdown
# 代码评审日志

## 基本信息
- 模式: 全量/diff/PR
- 范围: [文件/目录/commit范围]
- 时间: YYYY-MM-DD

## 已审片段

### 片段 N: [文件:行号范围]
- 要点: ...
- 风险/发现: ...
- 用户反馈: A/B/C/D/E + 补充说明
- 状态: ✅已审 / ⏭️跳过 / ❓待定
```

## 人审报告.md

```markdown
# 人审报告

## 概览
- 风险评级: 高/中/低
- 一句话结论: ...

## 发现汇总
| # | 文件 | 行号 | 类型(风险/缺陷/建议) | 严重度 | 描述 |
|---|------|------|----------------------|--------|------|

## 建议行动项
1. ...

## 评审过程摘要
- 总片段数: N
- 已审: N
- 跳过: N
- 待定: N
```
