## 容器契约

你在 sandbox 容器内, 不是宿主机. 宿主机环境文档 (`~/AGENTS.md`, `~/docs/`) 在这里不存在, 别找.
网络受宿主机管控 (白名单模式下出站默认拒): 访问不通先怀疑管控而非故障, 列出所需站点报给我; 长时间排查网络故障是浪费.
headed 浏览器 (`BROWSER_HEADED=true`, 登录墙场景) 显示选路: `WAYLAND_DISPLAY` 在场就连它 (窗口落在宿主机桌面, 我直接操作), 缺席用 `DISPLAY=:99` (noVNC 虚拟屏, 我经宿主机浏览器操作).
git remote 固定 `git://127.0.0.1:9418/<仓库名>`: 只准快进推当前分支, push 即交付 — 宿主机在母体目录审阅成果. 真远端 (github 等) 无 remote 无凭据, 别试.
任务改动收口后主动提交并推送, 不等我指令; 提交粒度按逻辑单元 — 单元完成且验证通过后一次 commit+push, 中间编辑攒到收口, 用最少的操作交付最多的结果.
密钥/token 只落在不会被 push 的位置.
