## 容器契约

你在 sandbox 容器内, 不是宿主机. 宿主机环境文档 (`~/AGENTS.md`, `~/docs/`) 在这里不存在, 别找.
网络白名单制: 出站默认拒. 访问被拒是预期行为, 列出所需站点报给我; 长时间排查网络故障是浪费.
git remote 固定 `git://127.0.0.1:9418/<仓库名>`: 只准快进推当前分支 (历史只增不改), push 即交付 — 宿主机在母体目录审阅成果. 真远端 (github 等) 物理不可达, 别试.
密钥/token 只落在不会被 push 的位置.
