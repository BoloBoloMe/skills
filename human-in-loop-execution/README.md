# HILE skill v2.24.1

Start at `SKILL.md`. Runtime agent routing starts at `references/agent/00-directory.md`. Human reviewers start at `references/human/00-start.md`.

v2.24.1 is suggest-and-confirm: the assistant may suggest HILE only for execution of an approved HILP handoff, and formal HILE starts only after explicit user confirmation plus a current handoff and workspace. Controlled execution requests without an approved HILP handoff route back to HILP instead of HILE intake. Trial-era handoffs are unsupported and should be regenerated by HILP v2.24.0.

Shared HILP/HILE schema compatibility is declared in `references/shared/compatibility-contract.yaml`.

HILE v2.24.1 clarifies the boundary between HILP execution units and HILE repository-aware Plan/Runbook execution.
