# 分支收尾

## 适用时机

执行任务完成、准备声明完成、提交、合并、创建 PR 或交付给用户前使用。

## 输入契约

- HILP execution handoff asset_ref。
- 执行计划或任务清单状态。
- 最新验证命令与输出。
- 代码审查结果和阻断项状态。
- 当前分支或工作区状态。

## 执行规则

1. 收尾前运行完成前验证，检查审查阻断项，确认 Critical 和 Important 已清零或明确阻断。
2. 检查没有蓝图外文件、没有禁止越界项命中。
3. 固定后续选项：本地合并、推送创建 PR、保留分支、丢弃工作。
4. 丢弃工作必须要求用户输入精确确认词，不得自动删除用户工作。
5. 合并或创建 PR 前后都要验证；验证失败不得继续，也不得给出 merge / PR 成功结论。
6. worktree cleanup 只在安全选项下执行，不自动删除用户工作。
7. 完成后输出 HILP 执行结果、偏差、新事实或重审触发。

## 禁止事项

- 不得在验证失败时声明完成。
- 不得在 Critical 未清零时继续。
- 不得自动合并、删除分支或清理工作区。
- 不得隐藏蓝图偏差、新事实或回滚风险。
- 不得把分支收尾当作 HILP 规划资产归档。

## 输出契约

输出完成检查结果、验证证据、审查状态、当前分支或工作区状态、四个后续选项、HILP 执行结果和重审触发判断。若不能收尾，输出阻断原因和 HILP 回退入口。

## 检查清单

- [ ] 新鲜验证已运行。
- [ ] 审查阻断项已处理。
- [ ] 禁止越界项未命中。
- [ ] 本地合并 / 创建 PR / 保留分支 / 丢弃 四选项已按需呈现。
- [ ] 删除或丢弃前有精确确认。
