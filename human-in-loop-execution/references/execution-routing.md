# 执行路由

## 适用时机

收到 HILP 执行交接后的执行、计划、测试、审查、调试或收尾请求时使用。

## 输入契约

- HILP design asset_ref: `stage-3/design-choice@vN [state=approved｜中文状态=已批准]`
- HILP blueprint asset_ref: `stage-4-5/implementation-blueprint@vM [state=approved｜中文状态=已批准]`
- HILP execution handoff asset_ref: `stage-6/execution-handoff@vK [state=<state>｜中文状态=<state_label>]`
- 执行入口检查：无阻断项。
- 当前任务状态：计划、实现、测试、审查、反馈、调试或收尾之一。
- 禁止越界项与停止并回退条件：来自执行交接资产。

## 执行规则

路由优先级固定如下：
1. HILP 资产校验：缺少已批准设计、已批准蓝图或执行交接时停止。
2. 越界检查：出现蓝图外文件、规划职责扩张、审批缺失或禁止越界项命中时回到 HILP 变更重审。
3. 当前任务状态：没有计划先写执行计划；已有计划按 subagent 或 inline 执行。
4. 失败触发：测试、构建、运行或验证失败时进入系统化调试，不猜测修复。
5. 审查触发：完成任务后先做规格与代码质量审查。
6. 收尾触发：声明完成、提交、合并或交付前先做完成前验证。

阶段名固定为：执行入口检查阶段、执行计划阶段、subagent 执行阶段、inline 执行阶段、TDD 实现阶段、代码审查阶段、review 反馈处理阶段、分支收尾阶段、HILP 重审回退。

## 禁止事项

- 不得跳过执行入口检查。
- 不得把草稿、待审批、待修订或已归档规划资产当作已批准输入。
- 不得用执行阶段补齐需求、设计或蓝图。
- 不得恢复被裁剪入口、命令、插件、hooks、assets 或测试工程。
- 不得在验证失败后路由到完成声明。

## 输出契约

输出当前阶段、绑定的 HILP 资产、执行范围、禁止越界项、停止并回退条件和下一步动作。若路由到 HILP 重审回退，说明触发原因、受影响执行内容和应回到的 HILP 阶段。
