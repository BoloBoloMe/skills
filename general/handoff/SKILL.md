---
name: handoff
description: 将当前对话内容压缩成一份交接文件, 以便其他 agent 接手.
disable-model-invocation: true
---

编写总结当前对话的交接文档, 供新 agent 了解前情和现状. 落盘到当前工作区 `docs/changes/handoff/YYYY-MM-DD-<简短标识>.md`.
保持高信息密度, 不写对后续工作低价值的内容;
只写其他文档没有的信息, 其他文档已有的信息写入 `必读推荐`;
遮蔽所有敏感信息, 如 API key/密码/个人身份信息.
除非我要求, 否则只描述信息, 不写 agent 的下一步动作;
若我提示了下一个会话将用于什么用途, 则将其视为对下一会话重点内容的描述, 并针对此用途审核交接文档的内容是否足够支撑, 补足信息缺口.

- *必读推荐*: 指引 agent 找到文档未包含的必读信息 (文件路径/代码位置/URL). 没有则写 `无`. 每项写明必读理由及补充信息内容.
- *路线图*: 从会话内容还原我的真实意图, 按发展脉络列出整件事情从起点到现在的每个关键里程碑, 评估距离目的地还剩多少.


完成标准: 文档落盘, 文件名含日期和简短标识; 最终回复仅含路径/摘要/必读推荐数量.
