---
name: handoff
description: 将当前对话压缩成交接文档,供另一个agent接手后续工作
disable-model-invocation: true
---

编写一份总结当前对话的交接文档,让新的agent能了解前情和现状,保存到当前工作区的 docs/handoff/ 目录下.

保持高信息密度.
不写对完成后续工作低价值的信息.
只陈述信息,不写agent下一步要做什么.
只写其他文档中没有的信息,其他文档中已有的信息写入`必读推荐`.

**必读推荐**: 告诉agent在哪找到交接文档中未包含的 **必读信息** (如文件路径/代码位置/网址URL),没有可以写`无`,
每一项都写明必读理由和包含哪些补充信息,.

**路线图**: 反思从会话内容透露出来的`我的真实意图`, 沿着事情的发展脉络列出`整件事情`从开始到现在的每个关键里程碑,总结现在距离目的地还剩多少距离.

遮蔽任何敏感信息,例如 API key/密码或个人身份信息.

如果我传入了参数,将其视为下一次会话重点的描述,并相应定制文档.
