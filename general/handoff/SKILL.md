description: 当前对话到交接文档的高密度压缩流程.
disable-model-invocation: true
---

编写总结当前对话的交接文档, 供新 agent 了解前情和现状, 落盘到当前工作区 `docs/handoff/YYYY-MM-DD-<简短标识>.md`.

保持高信息密度.
不写对后续工作低价值的信息.
只陈述信息, 不写 agent 下一步动作.
只写其他文档没有的信息; 其他文档已有的信息写入 `必读推荐`.

**必读推荐**: 指引 agent 找到文档未包含的 **必读信息** (文件路径/代码位置/URL). 没有则写 `无`.
每项写明必读理由及补充信息内容.

**路线图**: 从会话内容还原 `我的真实意图`, 按发展脉络列出 `整件事情` 从起点到现在的每个关键里程碑, 评估距离目的地还剩多少.

**当前认知上下文**: 仅当当前任务仍有相关认知状态时写入: 已确认知识缺口及处理状态, 尚未处理的盲区, 已明确接受的不确定性, 下一会话所需的讲解或追问深度. 不建立长期用户知识档案, 不记录已解决的个人知识缺口. 客观待查事实引用对应 Spec, 已确认决定引用 `DECISIONS.md`, 不在本节复制.

遮蔽所有敏感信息, 如 API key/密码/个人身份信息.

若我传入参数, 视为下次会话重点的描述, 据此定制文档.

完成标准: 文档落盘, 文件名含日期和简短标识; 存在任务相关认知状态时, `当前认知上下文` 只包含仍需传递的内容; 最终回复仅含路径/摘要/必读推荐数量.
