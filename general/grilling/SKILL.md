# 盘问

就事情的各个方面深入盘问我, 至达成共识. 把盘问建模成*决策树*: 每个决定分支出其下挂靠的决定. 按*轮次*推进, 每轮只问当前*前沿* — 即前置条件已定, 现在就能问而无须猜测我尚未给出的答案的问题. 一轮内问完整个前沿, 每个问题编号并附建议答案:

```
🤔 Q1 - <问题标题>: <问题正文, 可含多段与多个选项>

💡 <建议答案>
```

每轮我的答复重塑决策树: 已定决策把前沿外推到依赖它的那些问题, 重算前沿后进入下一轮; 答案依赖本轮仍开放问题的, 归*下一轮*. 前沿为空即所有分支都已访问, 无静默假定.

寻找*事实*是你的工作, 而不是我的. 前沿需要事实时派子代理去探查, 绝不向我询问任何你自己就能找到的信息. 
不要因此而阻塞: 进行中的探索是一个尚未确定的前提条件, 只有其下游的问题才需要等待子代理的报告 — 现在就可以询问前沿问题的其他部分了. 
决定权始终在我, 逐项交给我并等待, 绝不自问自答.

以事实为依据批判我的答复, 发现问题立即质疑. 
若答复呈现 模糊/凭直觉/说不出理由的强偏好/与已有决策冲突, 暗示这里有*隐性知识*: 设计问题测试我, 助我显化隐藏的决策逻辑, 直到足以支撑当前决定.

# 扫描盲区

关闭分支前扫一次盲区: 先问我 *是否派子代理反方攻击*, 拒绝则仅*自扫*, 同意则两者并行.

*反方攻击*: 派子代理调用 `opposing-viewpoint` skill 攻击当前决定, 子代理不继承盘问历史, 只接收当前决定/前提理由/已排除的候选项; 后台运行, 不阻碍父会话自扫; 失败则降级纯自扫, 禁止重试.

*自扫*: 提出我未提及但可能改变当前决定的重要因素, 无则跳过.

输出: 反方结论附你的评估 (成立与否及理由), 舍弃不成立的, 成立的与自扫结论一同汇报. 有能改变决定的发现, 就回到[盘问](#盘问)逐项解决.

# 完成标准

当前沿为空时, 盘问即告完成:
决策树的每个分支都已遍历完毕, 没有任何遗留的未言明假设.
不存在你已识别却未向我说明的重大认知缺口.
影响决定的*隐性知识*已显化到足以支撑决定.
已完成扫盲, 每项可能改变决定的发现已逐项决定.

# 边界

决策树关键分支全部满足完成标准后停下来, 询问*是否结束盘问*. 我确认结束前禁止采取任何行动.
