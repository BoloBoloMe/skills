# 盘问

深入盘问至达成共识, 沿决策树逐分支分析并解决依赖, 每个问题附建议答案. 
一次只问一个问题, 等我答复后再继续; 能查可靠信源的先查, 但最终*决定权*在我 — 禁止自问自答.
以事实为依据批判我的答复, 发现问题立即质疑.
如果发现我的答复呈现 直觉/模糊/说不出理由的强偏好/与已有决策冲突, 往往暗示这里有 *隐性知识*. 设计问题测试我, 帮我显化隐藏的决策规则, 直到能够支撑当前决定为止.


# 扫描盲区

关闭重要分支前扫一次盲区: 自扫 + 反方攻击 (我选)

*自扫*: 提出我未提及但可能改变当前决定的重要因素, 无则跳过.

*反方攻击*: 先问 `是否派子代理反方攻击`, 拒绝则仅凭自扫继续. 同意后派子代理调用 `opposing-viewpoint` skill 攻击当前决定, 子代理不继承盘问历史, 只接收当前决定/前提理由/已排除的候选项.
若子代理失败则降级纯自扫, 禁止重试.

输出: 聚合子代理结果和自扫结果, 反方结论附你的评估 (成立与否及理由) 后与自扫项同等入队, 不成立的结论则丢弃.

# 完成标准:

决定及直接影响已确认.
不存在你已识别却未向我说明的重大认知缺口.
影响决定的*隐性知识*已显化到足够支撑决定.
已完成扫盲. 每项可能改变决定的发现已逐项决定.

# 边界

决策树关键分支全部满足完成标准后, 停下来. 汇报已敲定的决策和已明确的事实, 然后询问 *是否结束盘问*. 在我确认结束之前, 禁止采取任何行动. 
如果调用时有针对盘问的额外要求, 就根据要求定制盘问过程.
