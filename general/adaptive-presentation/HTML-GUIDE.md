# 临时 HTML 展示

## 临时目录

首次生成页面时创建唯一目录, 后续复用:

```python
import tempfile
session_dir = tempfile.mkdtemp(prefix="pi-presentation-")
```

路径丢失或目录不存在时重新创建. 不写死平台路径. 绝对路径保存在会话上下文的 `presentation_session_dir`.

完成标准: 目录由标准临时目录 API 在运行时得出, 唯一且位于该 API 返回的临时目录内.

## 页面

语义化不重复 `.html` 文件名. 页面必须:

- 完整 HTML5, UTF-8, 可直接通过 `file://` 打开.
- 自包含 CSS 和必要脚本, 不依赖服务器/CDN/构建步骤/网络资源.
- 响应式: 窄屏和宽屏下不重叠, 不截断关键文字.
- 键盘: 所有交互可通过键盘完成, 不依赖鼠标/触摸.
- 颜色: 状态表达不只用颜色, 同时使用图标, 文字或形状区分.
- 视觉形式服务当前问题: 流程突出方向, 层级突出从属, 对比保持共同尺度.
- 禁止 Mermaid. 可用 CSS, inline SVG, Canvas 或少量原生 JavaScript.

### 页面状态对象

每个页面必须提供:

```javascript
window.__PRESENTATION_STATE__ = {
  version: 1,
  values: {}
};
```

- `version` 是整数, 当前只接受 `1`.
- `values` 是可 JSON 序列化的对象, 保存当前选择, 筛选和视图状态.
- 不保存完整事件历史.
- 无交互页面也必须提供空 `values`.
- 一次 JavaScript 求值读取整个对象.

### 有界交互

交互只在缩放, 筛选, 切换状态或比较视图能明显改善理解时才加入. 静态页面足够时不增加脚本.

**允许**: 方案选择, 视图切换, 细节展开/折叠, 筛选, 缩放/平移.

**禁止**: 复杂表单, 多步骤操作流, 拖拽编辑, 应用级原型.

最终确认必须在 chat 中完成, 页面交互状态只是辅助反馈.

### 安全

- 不写入密钥, Cookie, token, 认证头或无关仓库内容.
- 原始日志和业务数据只保留理解当前问题所需的最小片段.
- 外部输入按文本处理: 用 `textContent` 或安全 JSON 编码写入, 不拼成可执行 HTML/event handler/脚本.
- 关键结论和待确认事项不只在页面中, chat 中必须同步说明.

完成标准: 文件存在且可读, 无外部运行依赖, 内容与当前问题一致, 未泄露敏感信息, 状态对象可被一次 JS 求值读取.

## 交付

进入 HTML 分支时自动使用适配脚本通过 access-web 打开页面. 在 chat 中提供本地绝对路径链接, 一句话说明展示内容, 指出需要我观察/回答的具体问题.

若页面迭代, 创建新文件并保留旧版本. 反馈与最终决策以 chat 为准.

完成标准: 我能通过链接打开正确版本, 能仅凭 chat 文字知道页面目的和下一步.
