# Learning record 格式

Learning records 位于 `./learning-records/`, 用连续编号命名: `0001-slug.md`, `0002-slug.md`. 目录按需创建, 只有写第一条记录时才创建.

它们是教学版 ADR: 记录非显然学习, 关键洞见, 已声明的已有基础, 被纠正的误解, 或使命变化. 它们用于判断最近发展区.

## 模板

```md
# {学到或确认的短标题}

{1-3 句: 我学到了什么, 或确认了什么已有基础, 以及它为什么会影响后续教学.}
```

这就是完整格式. 一条 learning record 可以只有一个段落. 价值在于记录这件事现在已经成立, 以及它如何改变下一步教学, 而不是填满小节.

## 可选小节

只在真正有价值时加入. 大多数记录不需要.

- `status` frontmatter: `active` 或 `superseded by LR-NNNN`. 当早期理解后来被替代时使用.
- `## 证据`: 我如何展示了理解, 例如答对问题, 完成练习, 说明已有经验. 当这个判断以后可能被复查时有用.
- `## 后续影响`: 它解锁或排除了什么后续教学. 只有不显然时才写.

## 编号

扫描 `./learning-records/` 中已有文件, 找到最高编号, 加 1.

## 何时写 learning record

满足任一条件时写:

1. 我展示了对某个非平凡内容的真实理解. 不是接触过, 而是有证据表明我能正确使用它. 这会设定下一步教学的新起点.
2. 我披露了已有基础, 例如 "我已经会 X". 记录它, 避免以后重复教学. 同时记录我声称的深度.
3. 一个误解被纠正. 我之前相信错误内容, 现在理解为什么错. 这类记录价值高, 因为它预示相关主题的未来卡点.
4. 使命因学习而改变. 我发现自己在乎的目标不同于之前想象. 交叉链接 `MISSION.md`, 并更新使命.

## 不应写的内容

- 只是本轮覆盖过的材料. 覆盖不等于学习. 等到有证据再写.
- 已经被 `GLOSSARY.md` 紧定义捕捉的术语. 不要重复.
- 逐会话流水账. Learning records 不是日志, 而是能影响教学决策的洞见.

## 替代旧记录

如果后来的记录推翻或深化了早期记录, 不删除旧记录. 在旧记录 frontmatter 标记 `status: superseded by LR-NNNN`. 理解如何演化本身也是有用信号.

## 中文规则

标题, 正文, 证据, 后续影响都用中文组织. 文件名 slug 可用拼音或简短英文, 但页面标题必须中文.
