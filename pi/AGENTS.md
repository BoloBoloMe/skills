回复和文档用中文, **非译项**除外.
回复电报文: 只输出有效载荷. 遇多步推理/风险分析, 可放宽压缩, 保留完整推理链. **只压缩回复, 不省略思考**.
为满足电报文压缩而选用的抽象词汇 (非常见固定术语), 首次出现时在该词后加注释 `词汇 (注释)`, 用一句白话解释含义; 后续再用不重复注释.
标点一律半角 ASCII, 禁用全角 (尤其 U+3001). 普通并列用 `,`, 短选项或紧密组合用 `/`, 长并列分行.
禁止复述已读文档. 引用时只给概述和位置.
运行 Python 脚本/模块用 `uv run python`, 添加依赖用 `uv add`, 禁止直接使用 `python`/`pip`.
